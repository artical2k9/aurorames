# Implementation Plan: Service Decomposition — Extract Item Master, BOM & ECO

**Branch**: `111-service-decomposition` | **Date**: 2026-06-04 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/111-service-decomposition/spec.md`

## Summary

`work-order-service` currently hosts ItemMaster, BOM, ECO, and UserGridPreference controllers in violation of Constitution §XI (Service Boundary Integrity). A live incident (2026-06-02) demonstrated that Kafka consumer churn in `work-order-service` directly disrupted Item Master and BOM availability. This plan migrates those domains to correctly-owned services (`inventory-service`, `engineering-service`, `platform-service`), replaces the catch-all `/api/v1/**` gateway predicate with domain-specific routes, and converts the direct BOM→ECO Java call to a Kafka event.

## Technical Context

**Language/Version**: Java 21 LTS (Eclipse Temurin), TypeScript 5.x (Angular 21 — no frontend changes needed)

**Primary Dependencies**: Spring Boot 3.3, Spring Cloud Gateway, Apache Kafka (KRaft), Spring Data JPA, Hibernate 6 + Envers, Flyway, `mes-udf-lib`, `lib-common-security`, `lib-common-audit`

**Storage**: PostgreSQL 16 — new schemas: `inventory` (inventory-service), `engineering` (engineering-service); `platform` schema gains `user_grid_preferences` table

**Testing**: JUnit 5, Mockito, Testcontainers (PostgreSQL 16 + Kafka per service)

**Target Platform**: Docker Compose (Portainer); Linux containers

**Project Type**: Microservice decomposition — two new Spring Boot services, gateway config update, one platform-service migration, one work-order-service cleanup

**Performance Goals**: No regression on existing API latency; new services start within 60s

**Constraints**: Zero URL path changes (Angular frontend unchanged); existing `work_order` Flyway history untouched; Envers audit trail recreated in new schemas; no data loss for development UDF/preference data

**Scale/Scope**: 2 new services (~3–4k LOC each), 1 gateway YAML change, 1 platform-service migration, 1 cleanup PR
